## Wireworld Logic Gate Cellular Automaton

A 40x30 grid implementation of the Wireworld cellular automaton with four cell states: empty, conductor (orange), electron head (blue), and electron tail (white). Supports draw/erase tools, play/pause/step simulation controls, variable speed, and pre-loaded AND, OR, and NOT gate examples.

**Tech:** Vanilla JS, HTML5 Canvas, Tailwind CSS CDN. Supports mouse and touch input.

**How to use:** Select a draw tool (Conductor, Electron Head, Tail, or Eraser) and paint the grid. Load a preset gate example to see electrons flowing, then press Play to run the simulation or Step to advance one generation at a time.
